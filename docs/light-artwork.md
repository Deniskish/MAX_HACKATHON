# Светлая графика «Опоры»

Первая пастельная версия, сохранённая для сравнения; приложение её не загружает. Активный нейтральный набор описан в [light-artwork-neutral.md](light-artwork-neutral.md).

Восемь отдельных изображений созданы встроенным image_gen по существующим PNG и сохранены в lossless WebP с исходным альфа-каналом и размером. Исторические файлы находятся в [assets/light-pastel/](assets/light-pastel/) и не входят в публичную сборку. Тёмная тема использует исходный набор.

## Промпты

### hero-shapes.webp

Use case: style-transfer. Create a separate light-theme 3D hero PNG for a premium mobile business app. Input image is composition reference: preserve the two floating flattened glass pebble forms, large rounded disc lower-left and smaller inclined disc upper-right, same scale and placement on square canvas. Re-render material as luminous pale lavender crystal, translucent clear optical glass with pearl-white highlights and tiny soft peach reflections, lit with broad bright studio softboxes. Designed to sit on near-white #F4F3F8. Interiors should be bright and airy, NOT smoky, black, opaque, metallic or neon. Subtle lavender edge refraction defines silhouette against white. NO TEXT or logo. Genuine transparent RGBA background, no floor, no backdrop, no baked checkerboard or surrounding glow. Fill canvas similarly to reference, keep all edges visible. One standalone image.
