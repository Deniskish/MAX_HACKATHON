Импорт не проверяет цифровую подпись файла и не может доказать происхождение произвольного локального XML: оператор обязан получить оригинал из официального источника. HTTPS allowlist контролирует download/redirect; SHA-256 фиксирует импортированную версию. XML fixtures доказывают обработку структуры и ошибок, но не подтверждают наличие реальных записей. Фактический lookup реального ИНН в этой среде не выполнен: официальный индекс не наполнен.
