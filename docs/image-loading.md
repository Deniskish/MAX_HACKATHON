# Загрузка изображений

Исходные PNG и WebP сохранены в `miniapp/public/assets`. Интерфейс использует облегчённые WebP из `miniapp/src/assets/artwork`: для каждого изображения и темы подготовлены два разрешения. Цвета и композиция сохранены, альфа-канал после уменьшения сохраняется без потерь. Цветовые каналы сжаты с качеством 86, поэтому экспорт не является полностью lossless.

`ThemedImage` выбирает тему, а браузер — подходящий размер через `srcset` и `sizes`. Декоративные изображения внутренних страниц используют ленивую загрузку. Изображения первого экрана загружаются сразу, декодирование асинхронное. Неиспользуемая тема и исходники не скачиваются.

При сборке Vite добавляет хеш содержимого в URL. Express и Docker Nginx возвращают для таких изображений `Cache-Control: public, max-age=31536000, immutable`. После изменения картинки меняется URL: пользователю не нужно очищать кеш. HTML продолжает перепроверяться, API не затрагивается. Нехешированные исходники имеют прежний срок кеширования один час. Старые файлы сборки сохраняются существующим процессом публикации для открытых сессий.

Кеш зависит от браузера/MAX: при очистке данных или вытеснении файлов картинки будут скачаны снова, уже в облегчённом виде. Полностью автономный режим не добавлялся.

## Повторный экспорт

Из корня репозитория, Python с Pillow:

```sh
python -m pip install Pillow==12.3.0
python miniapp/scripts/optimize-artwork.py
npm run build --prefix miniapp
```

Экспорты и `miniapp/src/business/artwork.ts` хранятся в репозитории, поэтому для обычной сборки Python не нужен. Скрипт проверяет сохранение альфа-канала. `sizes.json` содержит веса исходников и экспортов.

## Проверка 25.09.2026

Chromium, 393×810, DPR 2, ограничение 1,6 Мбит/с и 150 мс задержки. Новый браузерный контекст для каждой темы; повторное открытие — в том же контексте. Измерение включает загрузку входа, автоматический ввод пароля и ожидание декодирования всех изображений главной. MAX Bridge заблокирован, чтобы не включать задержку внешнего скрипта. Это локальный сравнительный тест, не замер на реальном телефоне.

| Тема | Передано картинок до | После | Главная до | После | Повторно передано картинок |
| --- | ---: | ---: | ---: | ---: | ---: |
| Светлая | 2 979 166 Б | 266 264 Б | 16,83 с | 3,29 с | 0 Б |
| Тёмная | 4 292 533 Б | 264 734 Б | 23,39 с | 3,25 с | 0 Б |

Проверены обе темы, сохранение ввода при переключении и качество в мобильной вёрстке. Тест сервера проверяет годовой кеш WebP с хешем, обновление URL, условный запрос 304 и отсутствие вечного кеширования у исходников. Проверка публикации дополнительно проверяет наличие и заголовки оптимизированного изображения.

Основания: [Vite — обработка ресурсов](https://vite.dev/guide/assets), [MDN — Cache-Control](https://developer.mozilla.org/en-US/docs/Web/HTTP/Reference/Headers/Cache-Control), [MDN — img, srcset и sizes](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements/img).
