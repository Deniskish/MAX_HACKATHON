# Официальный каталог финансирования

`official-funding.snapshot.json` — шесть записей из первоисточников с URL, датой проверки, версией, состоянием приёма и неизвестными условиями. `OfficialSnapshotProvider` и валидатор исключают synthetic источники из runtime. Учебный набор остаётся только в `../tests/fixtures` для регрессионных тестов.

`FundingCatalogService` принимает provider; `matching.ts` детерминированно проверяет ограничения и потребность без ИНН и LLM. `null`/пустое значение — unknown. Закрытые/будущие отборы не eligible. Ограничения, которые не представлены фактами профиля, сохраняются в manualConditions как обязательные unknown. Софинансирование оценивается только по известным средствам; неуказанные инвесторы не считаются отсутствующими.

`strategy.ts` ранжирует варианты и явно требует проверить совместимость; лимиты не складываются. Поручительство — обеспечение. `legacy-adapter.ts` сохраняет редактор документов и старые типы, получая факты из того же snapshot. Новые решения о соответствии используют FundingMatch, а не legacy assessment.
